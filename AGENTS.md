# Инструкции и соглашения для AI-ассистентов (AGENTS.md)

## Цель проекта
`Aster` — это легковесный просмотрщик и редактор Markdown-файлов в стиле GNOME (Rust, GTK4, Libadwaita, WebKitGTK 6.0).
**Проект является обучающим!** Главная цель — не просто решить задачу, а помочь освоить базовые и продвинутые концепции разработки графических приложений на Rust и GTK4.

## Ключевые требования к коду и разработке:
1. **Подробные комментарии на русском языке**:
   - Весь исходный код (`src/**/*.rs`) должен быть снабжен детальными комментариями на русском языке.
   - Пояснять не только *что* делает код, но и *почему*:
     - Особенности разделяемого владения и мутабельности (`Rc<RefCell<...>>`) в однопоточном GUI.
     - Клонирование хэндлов виджетов перед перемещением в замыкания обработчиков сигналов GTK (GObject signals).
     - Регистрация действий (`gio::SimpleAction`) и назначение глобальных акселераторов/горячих клавиш (`set_accels_for_action`).
     - Динамическая стилизация через `gtk4::CssProvider`.
     - Архитектура виджетов Libadwaita (`adw::HeaderBar`, `adw::ViewStack`, `adw::PreferencesWindow`, `adw::SpinRow`, `adw::ComboRow`).
2. **Поддержание README.md и README_en.md в актуальном состоянии**:
   - `README.md` — основная русскоязычная версия, `README_en.md` — полный английский перевод.
   - При добавлении новых возможностей, изменении системных зависимостей или структуры проекта **обязательно** синхронно обновлять оба файла.
   - В `README.md` должна оставаться ссылка на английскую версию, а в `README_en.md` — ссылка на русскую.
   - Поддерживать инструкции по установке окружения для разных дистрибутивов Linux и настройки VS Code в обеих версиях.
3. **Поэтапные понятные коммиты в Git**:
   - Фиксировать изменения логическими шагами с понятными описаниями на русском языке, объясняющими суть добавленного кода.
4. **Чистота и архитектура**:
   - Модульная структура:
     - `main.rs` — точка входа, CLI (`--version`, `--help`), обработка `activate`/`open`.
     - `window.rs` — композиция окна, действия и связывание подсистем.
     - `window/style.rs`, `menus.rs`, `tabs.rs`, `dialogs.rs`, `preferences.rs`, `session.rs`, `actions.rs` — вынесенные части окна.
     - `document/mod.rs` — модель и состояние одной вкладки.
     - `document/search.rs`, `editor.rs`, `gutter.rs`, `links.rs`, `tests.rs` — поиск/замена, клавиатура, номера строк, ссылки и тесты.
     - `renderer.rs` — генерация HTML/CSS для GitHub Markdown.
     - `settings.rs` — модель конфигурации и персистентность (XDG).
     - `highlighter.rs`, `i18n.rs` — подсветка Markdown и переводы.
     - `shortcuts.rs` — перевод hardware keycode в латинские хоткеи для любой раскладки.
   - Иконка: `assets/aster.svg` (SVG-исходник, из него `install.sh` генерирует PNG).
   - Скрипты: `install.sh` (установка/удаление), `package-release.sh` (релизный архив), `Makefile` (краткие команды).
   - Аккуратная обработка ошибок (без беспричинных `unwrap`).
5. **Стандарты GNOME HIG**:
   - Следовать паттернам интерфейса GNOME Human Interface Guidelines.
