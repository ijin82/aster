# rmd-view 🦀

**rmd-view** — это обучающее легковесное приложение на **Rust**, **GTK4**, **Libadwaita** и **WebKitGTK 6.0** для просмотра и редактирования Markdown-документов в стиле GNOME.

Главная цель проекта — служить понятным практическим пособием по созданию графических Linux-приложений на Rust с соблюдением стандартов GNOME Human Interface Guidelines (HIG).

---

## 🎯 Основные возможности

- **Редактор текста** в стиле GNOME Text Editor:
  - **Отображение номеров строк**: левая колонка (gutter) с номерами строк, плавно синхронизированная с прокруткой и динамически адаптирующаяся по ширине и цвету к выбранной теме.
  - **Запоминание позиции курсора**: при повторном открытии файла курсор автоматически восстанавливается на той строке и колонке, где находился перед закрытием; для новых и ранее не открывавшихся файлов курсор устанавливается в начало документа `(0, 0)`, устраняя задержки («замирание») при открытии больших файлов.
  - **Независимая память прокрутки для каждого режима**: редактор и предпросмотр запоминают собственные позиции вертикальной прокрутки. При переключении режимов больше не выполняется хрупкий пересчет координат HTML-элементов — каждый режим просто возвращается туда, где пользователь его оставил. Позиции сохраняются для каждого файла и переживают перезапуск приложения.
  - **Бесшумная навигация**: отключен системный звуковой сигнал (error bell) при нажатии стрелок на границах документа (`Вниз` в конце или `Вверх` в начале текста).
  - Подсветка синтаксиса Markdown на лету через теги GTK (`src/highlighter.rs`): заголовки, жирный/курсивный шрифт, инлайн-код, блоки кода, списки, цитаты и ссылки.
  - Полноценная поддержка цветовых схем в редакторе (фон, цвет текста, курсор каретки и цвета токенов подсветки соответствуют выбранной теме).
  - Настраиваемая гарнитура моноширинного шрифта, мягкий перенос строк, отступы.
  - **Быстрое управление отступами строк (`Tab` / `Shift+Tab`)**: при наличии выделенного фрагмента текста нажатие `Tab` добавляет два пробела в начало каждой выделенной строки, а `Shift+Tab` удаляет до двух пробелов с начала строк (с сохранением границ выделения и поддержкой отмены через `Ctrl+Z`).
- **Предпросмотр Markdown в стиле GitHub**:
  - Быстрое переключение по `Ctrl+Tab` или переключателем в заголовке окна.
  - **Память прокрутки по режимам**: редактор и предпросмотр хранят раздельные позиции прокрутки, поэтому переключение не «прыгает» к случайному месту документа.
  - Рендеринг через WebKitGTK с оригинальной таблицей стилей `github-markdown-css`.
  - Поддержка расширений GFM (GitHub Flavored Markdown): таблицы, списки задач с чекбоксами (`- [x]`), сноски, зачеркивание, цитаты и блоки кода.
  - Автоматическая адаптация цветов под светлую и темную тему GitHub.
  - Загрузка локальных изображений (SVG, PNG, JPG, WebP) по относительным путям относительно открытого файла с передачей `base_uri`.
- **Работа с файлами и вкладками**:
  - **Вкладки документов** на базе `adw::TabView`: одновременное открытие нескольких Markdown-файлов, перетаскивание вкладок, контекстное меню, закрытие по `Ctrl+W` и создание новой вкладки по `Ctrl+T`. Полоса вкладок автоматически скрывается, когда открыт только один документ.
  - **Восстановление сессии**: при обычном запуске без аргументов приложение открывает все вкладки, которые были открыты в прошлой сессии, включая позиции курсора, прокрутки и активную вкладку (по аналогии с GNOME Text Editor). Незакрытые безымянные вкладки не сохраняются, так как их содержимое не связано с файлом на диске.
  - Открытие файлов (`Ctrl+O`, аргумент `rmd-view file.md`, файловый менеджер или D-Bus). Повторное открытие уже открытого файла переключает на существующую вкладку вместо создания дубликата.
  - Сохранение (`Ctrl+S`) и «Сохранить как...» (`Ctrl+Shift+S`).
  - **Индикация несохраненных правок** по стандартам GNOME HIG:
    - Элегантная точка `●` перед именем файла в заголовке окна (`● document.md — rmd-view`).
    - Подсветка кнопки «Сохранить» акцентным стилем `.suggested-action` (синяя кнопка), пока есть несохраненные правки.
    - Динамический тултип кнопки: *«Сохранить (Ctrl+S) — Есть несохраненные изменения»* / *«Save (Ctrl+S) — Unsaved changes»*.
  - Защита от потери данных: диалог подтверждения (`adw::MessageDialog`) при закрытии вкладки или окна с несохраненными правками. При закрытии окна доступна кнопка «Сохранить все».
  - Закрытие вкладки по `Ctrl+W`, закрытие окна и выход из приложения по `Ctrl+Q` или `Ctrl+F4`.
  - **Запоминание состояния и размеров окна**: сохранение развернутого состояния (maximized) и точных габаритов (ширина/высота).
- **Поиск по файлу (`Ctrl+F`)**:
  - Панель поиска с подсветкой всех найденных вхождений и навигацией.
- **Настройки (`Preferences`)**:
  - **Выбор языка интерфейса**: переключение между **Русским** и **English** с мгновенным обновлением UI и сохранением в настройках.
  - Выбор темы оформления: **Системная**, **GitHub Light**, **GitHub Dark**, **Dracula**, **Kimbie Dark**, **Solarized Dark**, **Solarized Light** (применяется одновременно к предпросмотру и к редактору кода).
  - Настройка боковых полей предпросмотра (padding в %, по умолчанию 5% с каждой стороны).
  - **Выбор из всех моноширинных шрифтов системы** (динамическое определение через Pango Context: `Cascadia Code`, `Fira Code`, `JetBrains Mono`, `Adwaita Mono`, `DejaVu Sans Mono`, `Liberation Mono` и др.).
  - Размер шрифта в редакторе (применяется на лету к существующему и к вновь вводимому тексту через CSS-правило `textview.editor-view text`).
  - Размер шрифта в окне предпросмотра.
  - **Переключатель отображения номеров строк** в режиме редактирования (`adw::SwitchRow`).
  - Сохранение настроек в формате JSON по стандарту XDG (`~/.config/rmd-view/settings.json`).

## 🛠️ Настройка окружения для разработки

### 1. Системные зависимости

Для компиляции требуются компилятор Rust (версии 1.75+) и заголовочные файлы библиотек GTK4, Libadwaita и WebKitGTK 6.0.

#### ALT Linux:
```bash
su -
apt-get update
apt-get install -y \
    libgtk4-devel \
    libadwaita-devel \
    libwebkitgtk6.0-devel
```

#### Fedora / RHEL:
```bash
sudo dnf install -y \
    gtk4-devel \
    libadwaita-devel \
    webkitgtk6.0-devel
```

#### Ubuntu / Debian (24.04+):
```bash
sudo apt update
sudo apt install -y \
    libgtk-4-dev \
    libadwaita-1-dev \
    libwebkitgtk-6.0-dev
```

#### Arch Linux:
```bash
sudo pacman -S --needed \
    gtk4 \
    libadwaita \
    webkitgtk-6.0
```

## 🚀 Сборка бинарного файла и запуск

### 1. Отладочная сборка (Debug)
Для быстрой компиляции и проверки во время разработки:
```bash
cargo build
```
Итоговый бинарник появится в `target/debug/rmd-view`.

### 2. Релизная оптимизированная сборка (Release)
Для получения максимальной скорости работы, отзывчивого интерфейса и минимального размера бинарника:
```bash
cargo build --release
```
Готовый исполняемый файл будет лежать в:
```bash
target/release/rmd-view
```

> **Совет по уменьшению размера бинарника (strip):**  
> Чтобы убрать отладочные символы и сделать бинарник компактнее:
> ```bash
> strip target/release/rmd-view
> ```

### 3. Установка в систему (опционально)
Чтобы запускать `rmd-view` из любой папки в терминале или ассоциировать с `.md` файлами:
```bash
# Установка в пользовательскую директорию (~/.cargo/bin)
cargo install --path .

# Либо копирование в системную директорию (от root/sudo)
sudo cp target/release/rmd-view /usr/local/bin/
```

### 4. Запуск приложения
```bash
# Запуск через cargo
cargo run -- test.md

# Прямой запуск собранного бинарника
./target/release/rmd-view test.md
```

## 📚 Архитектура проекта и чему здесь можно научиться

Исходный код снабжен детальными комментариями на русском языке:

- [`src/main.rs`](src/main.rs) — инициализация `adw::Application`, D-Bus ID, обработка сигналов `activate` и `open` (открытие файлов через аргументы командной строки или контекстное меню ОС).
- [`src/window.rs`](src/window.rs) — построение интерфейса и управление вкладками:
  - Использование `adw::HeaderBar`, `adw::TabView`, `adw::TabBar`, `gtk4::SearchBar`.
  - Клонирование хэндлов для захвата в замыкания сигналов GTK (`connect_clicked`, `connect_changed`).
  - Регистрация действий `gio::SimpleAction` и горячих клавиш приложения.
  - Восстановление и сохранение сессии (`session_files`, `session_active_document`).
  - Диалог настроек `adw::PreferencesWindow` и динамическое применение CSS через `gtk4::CssProvider`.
- [`src/document.rs`](src/document.rs) — одна вкладка документа:
  - Собственные `GtkTextBuffer`, `GtkTextView`, `WebKitWebView` и `adw::ViewStack` для каждого открытого файла.
  - Раздельная память прокрутки редактора (`GtkAdjustment`) и предпросмотра (`window.scrollY` через WebKit message handler).
  - Поиск `GtkTextIter::forward_search`, подсветка Markdown, отступы `Tab` / `Shift+Tab`.
  - CSS-шрифт редактора: правило действует на весь виджет, поэтому новый текст сохраняет выбранный размер и гарнитуру.
- [`src/highlighter.rs`](src/highlighter.rs) — встроенная подсветка синтаксиса Markdown для `GtkTextView` через создание и применение `GtkTextTag` (заголовки, жирный/курсив, код, ссылки, цитаты, списки) с палитрами для каждой темы оформления.
- [`src/i18n.rs`](src/i18n.rs) — типизированная интернационализация и переводы элементов интерфейса (русский и английский языки).
- [`src/renderer.rs`](src/renderer.rs) — парсинг Markdown с флагами GFM через `pulldown-cmark` и внедрение `github-markdown-css` во встроенный HTML-шаблон.
- [`src/settings.rs`](src/settings.rs) — сохранение структуры настроек и геометрии окна в JSON через `serde` и библиотека `dirs` для работы с XDG Base Directory.
