# Aster ✳️

![Иконка Aster](assets/aster.svg)

**Русский** · [English](README_en.md)   

**Aster** — это обучающее легковесное приложение на **Rust**, **GTK4**, **Libadwaita** и **WebKitGTK 6.0** для просмотра и редактирования Markdown-документов в стиле GNOME.

[Другой файл](AGENTS.md)      

Главная цель проекта — служить понятным практическим пособием по созданию графических Linux-приложений на Rust с соблюдением стандартов GNOME Human Interface Guidelines (HIG).

---

## 🎯 Основные возможности

- **Редактор текста** в стиле GNOME Text Editor:
  - **Отображение номеров строк**: левая колонка (gutter) с номерами строк, плавно синхронизированная с прокруткой и динамически адаптирующаяся по ширине и цвету к выбранной теме.
  - **Запоминание позиции курсора**: при повторном открытии файла курсор автоматически восстанавливается на той строке и колонке, где находился перед закрытием; для новых и ранее не открывавшихся файлов курсор устанавливается в начало документа `(0, 0)`, устраняя задержки («замирание») при открытии больших файлов.
  - **Независимая память прокрутки для каждого режима**: редактор и предпросмотр запоминают собственные позиции вертикальной прокрутки. При переключении режимов больше не выполняется хрупкий пересчет координат HTML-элементов — каждый режим просто возвращается туда, где пользователь его оставил. Позиции сохраняются для каждого файла и переживают перезапуск приложения.
  - **Полностью бесшумная работа**: в GTK отключены `gtk-error-bell`, звуки событий (`gtk-enable-event-sounds`) и звуковая обратная связь ввода (`gtk-enable-input-feedback-sounds`). Дополнительно в WebKit отключены медиа, Web Audio, медиапотоки и EME, поэтому предпросмотр Markdown не может воспроизводить звук.
  - Подсветка синтаксиса Markdown на лету через теги GTK (`src/highlighter.rs`): заголовки, жирный/курсивный шрифт, инлайн-код, блоки кода, списки, цитаты и ссылки.
  - Полноценная поддержка цветовых схем в редакторе (фон, цвет текста, курсор каретки и цвета токенов подсветки соответствуют выбранной теме).
  - Настраиваемая гарнитура моноширинного шрифта, мягкий перенос строк, отступы.
  - **Быстрое управление отступами строк (`Tab` / `Shift+Tab`)**: при наличии выделенного фрагмента текста нажатие `Tab` добавляет два пробела в начало каждой выделенной строки, а `Shift+Tab` удаляет до двух пробелов с начала строк (с сохранением границ выделения и поддержкой отмены через `Ctrl+Z`).
  - **Дублирование строки `Alt+D`**: копия строки под курсором вставляется ниже, курсор переходит на копию в ту же колонку.
  - **Переход к началу и концу документа (`Ctrl+Home` / `Ctrl+End`)**: курсор перемещается в начало или конец текущего файла, редактор прокручивается к соответствующему краю без горизонтального сдвига.
  - **Прокрутка по строкам (`Ctrl+Shift+↑` / `Ctrl+Shift+↓`)**: редактор прокручивается на одну видимую строку вверх или вниз, не перемещая курсор и не меняя выделение. В режиме мягкого переноса учитывается высота одного визуального ряда.
  - **Единый режим отображения (`Ctrl+Shift+P`)**: включает или выключает одновременно показ пробелов и мягкий перенос строк. Если хотя бы один из этих режимов был выключен, сочетание включает оба; если оба включены — выключает оба. Настройка сохраняется и применяется ко всем вкладкам.
  - **Переключение номеров строк (`Ctrl+Shift+L`)**: показывает или скрывает колонку с номерами строк во всех вкладках. Настройка сохраняется и переживает перезапуск приложения.
  - **Режим медитации `Ctrl+Shift+H`**: скрывает HeaderBar с меню и кнопками, оставляя только текст. Если открыта одна вкладка, редактор занимает всю площадь окна; повторное нажатие возвращает панель.
- **Предпросмотр Markdown в стиле GitHub**:
  - Быстрое переключение по `Ctrl+E` (как в Obsidian) или переключателем в заголовке окна.
  - **Память прокрутки по режимам**: редактор и предпросмотр хранят раздельные позиции прокрутки, поэтому переключение не «прыгает» к случайному месту документа.
  - Рендеринг через WebKitGTK с оригинальной таблицей стилей `github-markdown-css`.
  - Поддержка расширений GFM (GitHub Flavored Markdown): таблицы, списки задач с чекбоксами (`- [x]`), сноски, зачеркивание, цитаты и блоки кода.
  - Автоматическая адаптация цветов под светлую и темную тему GitHub.
  - Загрузка локальных изображений (SVG, PNG, JPG, WebP) по относительным путям относительно открытого файла с передачей `base_uri`.
  - **Безопасный предпросмотр**: Content Security Policy запрещает скрипты и сетевые запросы из Markdown, внешние ссылки открываются системным браузером, внутренние якоря (включая якоря заголовков) прокручиваются внутри страницы, а сам WebView не может уйти с текущего документа. Доступ к произвольным `file://` URL отключен.
- **Работа с файлами и вкладками**:
  - **Вкладки документов** на базе `adw::TabView`: одновременное открытие нескольких Markdown-файлов, перетаскивание вкладок, контекстное меню, закрытие по `Ctrl+W` и создание новой вкладки по `Ctrl+T`. Переключение вкладок по кругу — `Ctrl+Tab` / `Ctrl+Shift+Tab`; с последней вкладки переход идет на первую и наоборот. `Ctrl+Shift+T` восстанавливает последний закрытый файл в текущей сессии (стек до 50 вкладок, по аналогии с Chrome). Полоса вкладок автоматически скрывается, когда открыт только один документ.
  - **Восстановление сессии**: при обычном запуске без аргументов приложение открывает все вкладки, которые были открыты в прошлой сессии, включая позиции курсора, прокрутки и активную вкладку (по аналогии с GNOME Text Editor). Незакрытые безымянные вкладки не сохраняются, так как их содержимое не связано с файлом на диске.
  - **Открытие одного или нескольких файлов** (`Ctrl+O`, аргумент `aster file.md`, файловый менеджер или D-Bus). Диалог открытия стартует в папке активного документа или последнего открытого файла. Повторное открытие уже открытого файла переключает на существующую вкладку вместо создания дубликата.
  - Сохранение (`Ctrl+S`) и «Сохранить как...» (`Ctrl+Shift+S`).
  - **Индикация несохраненных правок** по стандартам GNOME HIG:
    - Элегантная точка `●` перед именем файла в заголовке окна (`● document.md — Aster`).
    - Подсветка кнопки «Сохранить» акцентным стилем `.suggested-action` (синяя кнопка), пока есть несохраненные правки.
    - Динамический тултип кнопки: *«Сохранить (Ctrl+S) — Есть несохраненные изменения»* / *«Save (Ctrl+S) — Unsaved changes»*.
  - Защита от потери данных: диалог подтверждения (`adw::MessageDialog`) при закрытии вкладки или окна с несохраненными правками. При закрытии окна доступна кнопка «Сохранить все».
  - Закрытие вкладки по `Ctrl+W`, закрытие окна и выход из приложения по `Ctrl+Q` или `Ctrl+F4`.
  - **Запоминание состояния и размеров окна**: сохранение развернутого состояния (maximized) и точных габаритов (ширина/высота).
- **Надёжность**:
  - **Реакция на изменения файла на диске**: для каждого открытого файла работает `gio::FileMonitor`. Если файл изменился извне и в документе нет несохранённых правок, Aster автоматически перечитывает его и показывает уведомление. Если правки есть, появляется toast «Файл изменён на диске» с кнопкой «Перезагрузить» — данные в редакторе не теряются молча.
  - **Восстановление безымянных вкладок после сбоя**: содержимое несохранённых безымянных вкладок сохраняется в `~/.local/share/aster/recovery.json` с задержкой около секунды после последней правки. После аварийного завершения черновики восстанавливаются при следующем запуске как изменённые безымянные вкладки. При штатном закрытии приложения файл восстановления удаляется.
- **Поиск и замена (`Ctrl+F`, `Ctrl+R`)**:
  - Панель поиска с подсветкой всех вхождений; текущее совпадение выделено более контрастно.
  - Счетчик `N из M`, кнопки «предыдущее/следующее», `Enter` / `Shift+Enter`, переход по кругу.
  - **Поиск в предпросмотре**: `Ctrl+F` ищет по видимому тексту отрендеренного HTML, подсвечивает все вхождения, показывает текущее и прокручивает к нему.
  - **Замена подстроки**: `Ctrl+R` открывает режим замены в редакторе. Поле «Заменить на…», кнопки «Заменить» и «Заменить всё». Обычная замена переходит к следующему совпадению; «Заменить всё» отменяется одним `Ctrl+Z` и выполняется одной операцией над буфером, без блокировки редактора на больших файлах.
  - При очень большом числе совпадений (больше 200) подсвечиваются первые 200 для отзывчивости; счётчик и навигация работают по полному списку, текущее совпадение подсвечивается всегда.
  - При закрытии панели подсветка снимается, запрос сохраняется; при повторном открытии результаты восстанавливаются.
- **Настройки (`Preferences`, `Ctrl+,`)**:
  - Открываются глобальной комбинацией `Ctrl+,`; хоткеи приложения работают в любой раскладке, включая русскую, потому что определяются по hardware keycode, а не по текущему keyval.
  - **Выбор языка интерфейса**: переключение между **Русским** и **English** с мгновенным обновлением UI и сохранением в настройках.
  - Выбор темы оформления: **Системная**, **GitHub Light**, **GitHub Dark**, **Dracula**, **Kimbie Dark**, **Solarized Dark**, **Solarized Light** (применяется одновременно к предпросмотру и к редактору кода).
  - Настройка боковых полей предпросмотра (padding в %, по умолчанию 5% с каждой стороны).
  - **Ширина табуляции** (1–8, по умолчанию 2) — сколько моноширинных знаков занимает существующий символ `\t` при отображении.
  - **Размер отступов** (1–8, по умолчанию 2) — сколько пробелов вставляют `Tab` и `Shift+Tab`. Табы в текст не вставляются, только пробелы.
  - **Мягкий перенос строк** (по умолчанию включен) — длинные строки переносятся по ширине окна.
  - **Показ пробелов и табов** (по умолчанию включен) — пробелы отмечаются точками, табы — горизонтальными линиями. Вместе с мягким переносом переключается по `Ctrl+Shift+P`.
  - **Выбор из всех моноширинных шрифтов системы** (динамическое определение через Pango Context: `Cascadia Code`, `Fira Code`, `JetBrains Mono`, `Adwaita Mono`, `DejaVu Sans Mono`, `Liberation Mono` и др.).
  - Размер шрифта в редакторе (применяется на лету к существующему и к вновь вводимому тексту через CSS-правило `textview.editor-view text`).
  - Размер шрифта в окне предпросмотра.
  - **Переключатель отображения номеров строк** в режиме редактирования (`adw::SwitchRow`) и горячая клавиша `Ctrl+Shift+L`. Номера выравниваются по первому визуальному ряду, поэтому у длинной строки с мягким переносом номер остается у ее начала, а не в середине.
  - Сохранение настроек в формате JSON по стандарту XDG (`~/.config/aster/settings.json`).

## 🛠️ Настройка окружения для разработки

### 1. Установка Rust

Для сборки нужен компилятор Rust версии 1.75 или новее. Рекомендуемый способ установки — официальный установщик `rustup`:

```bash
curl https://sh.rustup.rs -sSf | sh
```

Скрипт предложит вариант установки; достаточно выбрать стандартный профиль. После завершения подключите окружение Cargo к текущей сессии:

```bash
source "$HOME/.cargo/env"
```

Проверьте установку:

```bash
rustc --version
cargo --version
```

Если Rust уже установлен через `rustup`, обновите инструменты командой:

```bash
rustup update
```

> В некоторых дистрибутивах `rustc` и `cargo` можно установить из репозитория, но для проекта рекомендуется `rustup`: он не зависит от версии пакетов дистрибутива и позволяет переключать toolchain.

### 2. Системные зависимости

Дополнительно для компиляции требуются заголовочные файлы библиотек GTK4, Libadwaita и WebKitGTK 6.0.

#### ALT Linux:
```bash
su -
apt-get update
apt-get install -y \
    libgtk4-devel \
    libadwaita-devel \
    libwebkitgtk6.0-devel
```

#### Fedora / RHEL:
```bash
sudo dnf install -y \
    gtk4-devel \
    libadwaita-devel \
    webkitgtk6.0-devel
```

#### Ubuntu / Debian (24.04+):
```bash
sudo apt update
sudo apt install -y \
    libgtk-4-dev \
    libadwaita-1-dev \
    libwebkitgtk-6.0-dev
```

#### Arch Linux:
```bash
sudo pacman -S --needed \
    gtk4 \
    libadwaita \
    webkitgtk-6.0
```

## 🚀 Сборка бинарного файла и запуск

### 1. Отладочная сборка (Debug)
Для быстрой компиляции и проверки во время разработки:
```bash
cargo build
```
Итоговый бинарник появится в `target/debug/aster`.

### 2. Релизная оптимизированная сборка (Release)
Для получения максимальной скорости работы, отзывчивого интерфейса и минимального размера бинарника:
```bash
cargo build --release
```
Готовый исполняемый файл будет лежать в:
```bash
target/release/aster
```

> **Совет по уменьшению размера бинарника (strip):**  
> Чтобы убрать отладочные символы и сделать бинарник компактнее:
> ```bash
> strip target/release/aster
> ```

### 3. Установка через `install.sh`

Скрипт собирает релизный бинарник, устанавливает его в `~/.local/bin`, иконки в
`~/.local/share/icons/hicolor`, desktop-entry в `~/.local/share/applications`
и умеет полностью удалять приложение:

```bash
# Интерактивное меню (установка / пересборка / удаление)
./install.sh

# Установка (при отсутствии бинарника выполнит cargo build --release)
./install.sh install

# Чистая пересборка и установка
./install.sh rebuild

# Установить уже собранный бинарник без сборки
./install.sh lite

# Ярлык на рабочем столе
./install.sh shortcut

# Полное удаление: бинарник, иконки, меню, настройки и сессия
./install.sh uninstall
```

Для установки иконок в PNG-форматах скрипт использует `rsvg-convert` или
Python-привязки PyGObject/Rsvg. Если их нет, устанавливается только SVG-иконка.

### 4. Сборка релизного архива

```bash
# Подготовить релиз версии v0.8.1 одной командой
./package-release.sh v0.8.1

# Без аргумента используется текущая версия из VERSION
./package-release.sh
```

Если версия передана аргументом (или через переменную `VERSION`), скрипт сам
обновляет `VERSION`, `Cargo.toml` и `Cargo.lock` — вручную править файлы не
нужно. Затем он проверяет вывод `aster --version`, собирает релиз, удаляет
отладочные символы, складывает бинарник, `install.sh`, иконку, `README.md`,
`README_en.md` и лицензию в `dist/aster-vX.Y.Z-linux-<arch>.tar.gz` и создает `.sha256`.

После подготовки релиза не забудьте закоммитить обновленные `VERSION`,
`Cargo.toml` и `Cargo.lock`.

### 5. Запуск приложения

```bash
# Запуск через cargo
cargo run -- test.md

# Прямой запуск собранного бинарника
./target/release/aster test.md

# Проверка версии без запуска графического интерфейса
./target/release/aster --version
```

При запуске из терминала Aster, как `code` из VS Code, сразу возвращает
приглашение, а GUI продолжает работать отдельным процессом. Вывод GTK
записывается в `~/.cache/aster/aster.log`. Чтобы оставить процесс на переднем
плане и видеть логи в консоли:

```bash
ASTER_FOREGROUND=1 aster test.md
```

## 📚 Архитектура проекта и чему здесь можно научиться

Исходный код снабжен детальными комментариями на русском языке:

- [`src/main.rs`](src/main.rs) — инициализация `adw::Application`, D-Bus ID, обработка сигналов `activate` и `open` (открытие файлов через аргументы командной строки или контекстное меню ОС).
- [`src/window.rs`](src/window.rs) — композиция окна, `adw::HeaderBar`, `adw::TabView`, `adw::TabBar` и регистрация действий:
  - Клонирование хэндлов для захвата в замыкания сигналов GTK (`connect_clicked`, `connect_changed`).
  - Регистрация действий `gio::SimpleAction` и горячих клавиш приложения.
  - Связывание независимых подсистем окна.
- [`src/window/`](src/window/) — вынесенные части окна:
  - `style.rs` — темы, CSS редактора, шрифты, отключение звука;
  - `menus.rs` — главное меню и меню вкладок;
  - `tabs.rs` — активная вкладка и заворот `Ctrl+Tab`;
  - `dialogs.rs` — сохранение, unsaved-диалоги и «О программе»;
  - `preferences.rs` — `adw::PreferencesWindow`;
  - `session.rs` — сохранение сессии и геометрии окна;
  - `actions.rs` — регистрация действий `win.*` и связанных зависимостей.
- [`src/document/mod.rs`](src/document/mod.rs) — модель и состояние одной вкладки:
  - Собственные `GtkTextBuffer`, `GtkTextView`, `WebKitWebView` и `adw::ViewStack` для каждого открытого файла.
  - Загрузка/сохранение, режимы редактор/предпросмотр, заголовок вкладки, темы и сессионное состояние.
- [`src/document/search.rs`](src/document/search.rs) — поиск, замена и поиск по видимому HTML.
- [`src/document/editor.rs`](src/document/editor.rs) — `Tab`/`Shift+Tab`, дублирование строки, клавиатурные границы и восстановление курсора.
- [`src/document/gutter.rs`](src/document/gutter.rs) — номера строк.
- [`src/document/whitespace.rs`](src/document/whitespace.rs) — отрисовка пробелов и табов поверх редактора.
- [`src/document/links.rs`](src/document/links.rs) — политика ссылок в предпросмотре.
- [`src/document/tests.rs`](src/document/tests.rs) — тесты документа.
- [`src/highlighter.rs`](src/highlighter.rs) — встроенная подсветка синтаксиса Markdown для `GtkTextView` через создание и применение `GtkTextTag` (заголовки, жирный/курсив, код, ссылки, цитаты, списки) с палитрами для каждой темы оформления.
- [`src/i18n.rs`](src/i18n.rs) — типизированная интернационализация и переводы элементов интерфейса (русский и английский языки).
- [`src/renderer.rs`](src/renderer.rs) — парсинг Markdown с флагами GFM через `pulldown-cmark` и внедрение `github-markdown-css` во встроенный HTML-шаблон.
- [`src/shortcuts.rs`](src/shortcuts.rs) — независимое от раскладки сопоставление hardware keycode с латинскими горячими клавишами (Wayland/X11 fallback).
- [`src/settings.rs`](src/settings.rs) — сохранение структуры настроек, геометрии окна, позиций прокрутки и списка вкладок в JSON через `serde` и библиотеку `dirs` для работы с XDG Base Directory.
- [`install.sh`](install.sh) — установка и удаление приложения: сборка, `~/.local/bin`, SVG/PNG-иконки, desktop-entry, ярлык на рабочем столе.
- [`package-release.sh`](package-release.sh) — проверка версии, релизная сборка, `strip`, `tar.gz` и контрольная сумма SHA-256.
- [`Makefile`](Makefile) — краткие команды `make build`, `make test`, `make install`, `make package`.
- [`assets/aster.svg`](assets/aster.svg) — исходная векторная иконка Aster: лист Markdown-документа с янтарной звёздочкой. `install.sh` устанавливает SVG и сгенерированные PNG-размеры (16–512 px).
